# TikTok 短视频内容生态数据分析

基于 TikTok 公开数据集，分析短视频内容的传播规律与用户互动行为，为内容运营提供数据支撑。

## 📊 项目背景

短视频平台内容竞争激烈，什么样的视频更容易爆？什么样的内容用户更愿意互动？本项目通过对 19,084 条 TikTok 视频数据的多维度分析，揭示爆款内容的特征。

## 📁 数据集

- **数据来源**：Kaggle - TikTok User Engagement Data
- **数据量**：19,084 条视频记录
- **字段**：视频时长、内容类型（主张类/观点类）、博主认证状态、博主账号状态、播放量、点赞量、评论量、分享量、下载量

## 🔧 技术栈

- Python 3.13
- Pandas（数据清洗与分析）
- Matplotlib（数据可视化）
- JupyterLab（交互式分析）

## 📈 核心发现

| 序号 | 发现 | 业务建议 |
|---|---|---|
| 1 | 16-30秒是黄金时长，播放量比其他时长高40% | 视频时长控制在16-30秒 |
| 2 | 冷知识/事实类（主张类）播放量是观点类的100倍 | 多做干货内容，少做个人吐槽 |
| 3 | 用户爱点赞爱转发，懒得评论 | 重点关注点赞和分享指标 |
| 4 | 认证身份与播放量无正相关 | 专注内容质量，不必迷信认证 |
| 5 | 被封账号播放量反而高（平台审核滞后） | 违规博流量不可持续 |
